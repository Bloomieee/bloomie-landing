# Video Assets for Bloomie Landing Page

This directory contains video assets for the Bloomie landing page.

## Required Videos

### Product Demo Video
- **Files needed:**
  - `bloomie-product-demo.mp4` - Main product demonstration video
  - `bloomie-product-demo.webm` - WebM format for better browser compatibility
  - `video-poster-product.jpg` - Poster image for video preview

### Team Introduction Video
- **Files needed:**
  - `bloomie-team-intro.mp4` - Team introduction video
  - `bloomie-team-intro.webm` - WebM format for better browser compatibility
  - `video-poster-team.jpg` - Poster image for video preview

## Caption Files (Accessibility)
- `product-captions-en.vtt` - English captions for product demo
- `product-captions-es.vtt` - Spanish captions for product demo
- `team-captions-en.vtt` - English captions for team video
- `team-captions-es.vtt` - Spanish captions for team video

## Video Specifications
- **Format:** MP4 (H.264) and WebM for broad compatibility
- **Resolution:** 1920x1080 (Full HD) recommended
- **Duration:** 2-3 minutes maximum for optimal engagement
- **Aspect Ratio:** 16:9
- **File Size:** Under 50MB for good loading performance

## Poster Images
- **Format:** JPEG
- **Resolution:** 1920x1080 to match video aspect ratio
- **Quality:** High quality but optimized for web

## Accessibility Features
- All videos include multiple caption tracks
- Videos have proper ARIA labels
- Fallback download links provided
- Keyboard navigation support
